# Projet de Reconnaissance Vocale

## Description
Ce projet utilise la reconnaissance vocale pour capturer la voix, retranscrire le texte, extraire des mots-clés, et répondre vocalement. Il inclut également une fonctionnalité de discussion avec une IA capable de faire des blagues et de rire.

## Fonctionnalités
- Capture de voix (SpeechRecognition)
- Retranscription écrite
- Récupération de mots-clés (ex: "donne moi l'heure", reconnait le mot "heure", porcupine)
- Retranscription vocale (pyttsx3)
- Discussion (IA) capable de faire des blagues et de rire (chatbotai, openai)

## Installation
1. Clonez le dépôt :
    ```sh
    git clone https://github.com/Tolram89/projet-prog.git
    cd projet-prog
    ```

2. Installez les dépendances :
    ```sh
    pip install -r requirements.txt
    ```

## Utilisation
1. Lancez l'application :
    ```sh
    python main.py
    ```
